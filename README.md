# Project Management System (PMS)

A full-stack web application for managing projects, tasks, and team members in one place. The system provides user authentication, project management, task organization, and project tracking features.

## Features

* User Signup & Login
* JWT Authentication
* Create, Edit & Delete Projects
* Project Details & Team Members
* Task Management
* Project Status & Deadlines
* Search & Filtering
* Dashboard
* Dark Mode

## Technologies

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
